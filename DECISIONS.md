3. Decisions Still Required

The following decisions must be researched and reviewed before implementation:

- Coin symbol and smallest unit
- Block time
- Initial block reward
- Mining reward schedule
- Halving or alternative reward mechanism
- Difficulty adjustment algorithm
- Block size and weight limits
- Cryptographic hash algorithm
- Digital signature algorithm
- Address format
- Transaction and block serialization
- Network protocol and port
- Genesis block parameters

4. Security Principles

- Use established and reviewed cryptographic algorithms.
- Never invent a new cryptographic algorithm without expert review.
- Validate every transaction and block independently.
- Protect private keys.
- Test consensus rules carefully.
- Require independent security review before any real launch.

5. Decision Status

A decision becomes final only after its technical reasoning, security implications, and compatibility with the protocol have been reviewed.

No undecided parameter should be treated as a finalized network rule.
