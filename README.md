# XEVRITHON

XEVRITHON is an independent cryptocurrency and blockchain software project.

## Project Goals

- Independent blockchain network
- Maximum coin supply: 17,000,000 XVT (provisional symbol)
- Modified Proof of Work consensus
- Secure digital wallets
- Peer-to-peer networking
- Cryptographic transaction verification
- Transparent and verifiable coin issuance

## Security Principles

- Use established cryptographic standards.
- Never invent custom cryptography.
- Validate every transaction.
- Enforce the maximum coin supply through consensus rules.
- Test thoroughly before any public network launch.

## Development Status

Early development.

This project is not yet a production cryptocurrency.
